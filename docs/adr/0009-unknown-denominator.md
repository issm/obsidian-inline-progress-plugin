# 0009: 分母が不明な進捗を、塗りなしの破線のバーで表す

- 状態: 採用
- 日付: 2026-10-24

## 状況

進捗の分母（全体の数）が分からないことがある。たとえば、終わりが決まっていない作業で、これまでに5つ終えた、というときである。このとき、割合では描けない。一方で、完了数は書きたいし、ほかの進捗バーと並べたときに、見た目がそろっていてほしい。

## 決定

- `/` のうしろ（分母）が不明なことを、次の書式で表す。すべて同じ意味とする。
  - `?` または `-`（例: `5/?`、`5/-`）
  - 範囲の終了が不明: `13-?`、`13-`
  - 範囲の開始が不明: `?-26`、`-26`
  - どちらも不明: `?-?`、`-?`、`?-`
- 範囲の両端が数字のとき（`13-26`）だけ、これまでどおり範囲が確定する（[ADR 0008](0008-range-notation-for-target-values.md)）。
- 分母が不明なときの表示:
  - ラベルは `完了数/??`（例: `5/??`）。`nolabel` で消せる。
  - バーは表示するが、塗りは無い。背景の代わりに、破線の枠で描く。目盛り線も無い。
  - 満了の色（緑）にはならない。
- 位置指定（`1,3,5/?`）も許可する。区画の数が分からず位置を描けないので、位置の範囲は検査せず、重複を除いた個数を完了数とする（`3/??`）。
- 部分的に分かっている範囲（`13-?` など）の、分かっている側の値は使わない。位置の範囲の検査にも使わない。
- 破線の色は CSS 変数 `--inline-progress-unknown-color`（既定 `--text-faint`）で変えられる。
- アクセシビリティ: 最大値が分からないので、`aria-valuenow` と `aria-valuemax` は付けない（不確定の進捗として扱われる）。完了数は `aria-valuetext` で伝える。

## 検討した代替案

- 背景色だけを別の色にする。ページの背景に近い色では、バーの範囲が見えない。明るい色にしても、通常のバーとの違いが色だけになる。色の違いに気づきにくい人もいる。
- 斜めの縞で背景を塗る。長さが定まらない進捗バーによくある表現だが、通常のバーに近く、「空」であることが伝わりにくい。
- 塗りの空いた位置まで目盛り線を描く。区画の数が分からないので、描けない。
- 位置指定を不正として扱う。個数指定とそろわない。完了数を数えられるので、許可した。
- 分かっている側の値（`13-?` の 13 など）で、位置の範囲を検査する。分母が不明なときは塗らないため、検査の利点が小さく、規則が複雑になる。

## 結果

- 終わりの決まっていない作業も、完了数を書き、ほかのバーと並べて見られる。
- 書き間違いの検出が、一部ゆるくなる。たとえば `5/-26` は、`-26` の誤記かもしれないが、分母不明として描画される。
- 書式の範囲は広い（`?`、`-`、省略）。`5/13-` のような途中で終わった書き方も、分母不明になる。
- 破線の枠は、境界の線を 1px ぶん使うので、バーの内側の高さが、通常より 2px 小さい。
