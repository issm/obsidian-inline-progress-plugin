# 0003: 不正な値は描画せず、元のテキストを残す

- 状態: 採用
- 日付: 2026-10-24

## 状況

`13/12`（個数が総数を超える）、`0,13/12`（位置が範囲外）、`1/0`（総数が0）、未知のオプションなど、解釈できない表記が書かれることがある。このとき、どう表示するかを決める必要がある。

## 決定

- 解釈できない表記は、バーに置き換えず、元のテキストをそのまま表示する。
- 未知のオプション（例: `10/12; foo`）も、値全体を不正として扱う。オプションだけを無視して、バーは描画する、ということはしない。

## 検討した代替案

- エラー用の表示（赤い印など）に置き換える。表示は目立つが、実装が増え、ノートの見た目を変えてしまう。
- 範囲外の値を、総数に丸めて描画する。実際の進捗と違う表示になる。
- 未知のオプションだけを無視して描画する。typo（`nolable` など）に気づけない。

## 結果

- 書き間違えた表記は、ソースのまま見えるので、利用者が気づきやすい。
- 利用者への通知（警告など）はない。気づくのは、バーにならないことを見たときに限る。
