# 0011: 設定は CSS で反映し、`label` オプションを足す

- 状態: 採用
- 日付: 2026-10-24

## 状況

設定画面から、バーの幅・太さ・左右の余白と、ラベルの既定の表示を変えられるようにする（[ADR 0005](0005-appearance-via-css-variables.md) で見込んでいた）。

設定を変えたとき、表示済みのバーにすぐ反映したい。ところがライブプレビューのテーブルのセルは、本体とは別のエディタで表示されるうえ、描画済みの要素が再読み込みまで作り直されない。ラベルの表示を、描画のときに決める方式にすると、セルに反映されなかった。

## 決定

- 設定は `data.json` に保存し、`body` に反映する。表示済みの要素は作り直さない。
  - 寸法は、`--inline-progress-width` / `-height` / `-margin-start` / `-margin-end` を `body` の CSS 変数に設定する。空欄は変数を外し、`styles.css` の既定値に従う。
  - ラベルの既定は、オフのとき `body` に `inline-progress-hide-label` クラスを付ける。
- 左右の余白は別々の変数にする。表のセルで、左だけ詰めたいことがあるため。ADR 0005 の `--inline-progress-margin`（左右共通）は廃止した。
- ラベルは常に DOM に作り、表示するかは CSS が決める。
  - 記法に `label` オプションを足す。`nolabel` のフィールドには `label-hide`、指定なしには `label-auto` を付ける。`label` で明示したものは、どちらも付けない。
  - `label-hide` は常に隠す。`label-auto` は、`body` のクラスがあるときだけ隠す。`label` は常に表示する。
  - `label` と `nolabel` を両方指定した値は不正値（typo に気づけるようにする。ADR 0003）。
- ラベルの内容は、従来どおり `完了数/総数` のままにする。

## 検討した代替案

- 設定を描画関数に渡し、変更時に再描画する。ライブプレビューは、エディタごとに合図を送れば作り直せるが、テーブルのセルは再読み込みまで反映されなかった。閲覧モードも再描画の呼び出しが必要になる。
- ラベルの内容（`3/12` か値そのものか）を選べる設定。今回は、現状のままにすることにした。
- `nolabel` のときはラベルを作らない。設定を CSS で切り替える方式では、作る・作らないは描画時に固定されてしまう。

## 結果

- 設定の変更は、閲覧モード・ライブプレビュー・テーブルのセルのどこでも、すぐ反映される。
- 描画関数は、設定を受け取らない純粋な関数のままになる。
- `nolabel` のラベルも DOM には残り、`display: none` で隠れる。
- ADR 0005 の `--inline-progress-margin` を使っている CSS スニペットは、効かなくなる。
- ポップアウトウィンドウは `body` が別なので、`window-open` で設定を反映し直す。
