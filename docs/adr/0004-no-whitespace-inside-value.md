# 0004: 値の内側には空白を置けない

- 状態: 採用
- 日付: 2026-10-24

## 状況

`1,3,5/12` のような値は、`1, 3, 5 / 12` のように空白を入れて書くこともできてしまう。空白を許すと、書き方の揺れが増え、解析の規則も複雑になる。

## 決定

- 値（`完了/総数` の部分）の内側には、空白を置けない。空白があれば不正な値とする（[0003](0003-invalid-values-are-left-as-text.md)）。
- 次の位置の空白は許容する。
  - `progress::` の直後（`[progress:: 10/12]` の形で書くため）
  - `;` の前後
  - 値の前後

## 検討した代替案

- 値の内側の空白もすべて許容する。書き方の揺れが増える。
- 空白をまったく許容しない（`[progress::10/12]` のみ）。Dataview のインラインフィールドの慣習（コロンのあとに空白を置く）と合わない。

## 結果

- 値の解析は、1つの正規表現（`^([\d,]+)\/(\d+)$`）で書ける。
- `1, 3/12` は描画されない。利用者は空白を詰める必要がある。
