# 0002: オプションは `;` 区切りで値のうしろに書く

- 状態: 採用
- 日付: 2026-10-24

## 状況

ラベルを表示しない指定など、表示を個別に変えるオプションが必要になった。今後、オプションが増える可能性がある。また、Markdown の表の中でも使えるようにしたい。

## 決定

- 値のうしろに `;` を置き、その先にオプション名を書く。複数ある場合も `;` で続ける。
  - 例: `[progress:: 10/12; nolabel]`
- 現在のオプションは `nolabel`（ラベルを表示しない）のみ。
- `;` の前後の空白は許容する。空のオプション（末尾の `;` など）は無視する。

## 検討した代替案

- `|` で区切る。Markdown の表の中では、セルの区切りと衝突し、エスケープが必要になる。
- 空白で区切る（`10/12 nolabel`）。`1, 3, 5 / 12` のように空白入りで書かれたとき、値とオプションの境目が曖昧になる。
- オプションごとに別のフィールド名にする（`[progress-bar:: 10/12]`）。オプションが増えると、フィールド名の組み合わせが増える。

## 結果

- 表の中でも、エスケープなしで書ける。
- `width=12em` のような値付きのオプションも、同じ形式で足せる。
- 未知のオプションの扱いは [0003](0003-invalid-values-are-left-as-text.md) に従う。
