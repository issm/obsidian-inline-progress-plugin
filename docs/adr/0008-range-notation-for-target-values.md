# 0008: 進捗の対象を `開始-終了` の範囲で指定できるようにする

- 状態: 採用
- 日付: 2026-10-24

## 状況

進捗の対象が、1から始まる連番とは限らない。たとえば 13〜26 のように、途中から始まる範囲を扱いたい。このとき、位置指定では、範囲内の値（13、15、18 など）をそのまま書けるようにしたい。

## 決定

- 値の `/` のうしろを、`総数` に加えて `開始-終了` の形でも書けるようにする。
  - `3/13-26`: 13〜26 のうち、先頭から3個が完了（13・14・15）
  - `13,15,18/13-26`: 13〜26 のうち、13・15・18 が完了
- 範囲は両端を含む。`13-26` は 14 個である。
- ラベルの分母と目盛りなどの総数は、範囲の区画数（`終了 - 開始 + 1`）にする。ラベルに範囲の開始や終了の値は出さない。たとえば `3/13-26` のラベルは `3/14` である。
- 位置指定の値は、範囲の先頭から数えた番号ではなく、範囲内の値そのものを書く。範囲の外の値は不正とする。
- `/総数` は `/1-総数` と同じ。既存の記法の意味は変わらない。
- 開始が終了を超える範囲（`26-13`）は不正とする。開始は 0 以上の整数で、0 から始まる範囲も書ける。
- 個数指定とカンマによる位置指定の区別（[ADR 0001](0001-position-notation-uses-comma.md)）、値の内側に空白を置けない規則（[ADR 0004](0004-no-whitespace-inside-value.md)）、不正な値の扱い（[ADR 0003](0003-invalid-values-are-left-as-text.md)）は、そのまま範囲指定にも適用する。

## 検討した代替案

- 範囲を、終了を含まない半開区間にする。ご要望の例で分母が 13 と書かれていたため、一度検討した。ただ、`1-12` が 11 個になり、既存の `/12`（12個）と食い違う。また、`13-26` を「13から26まで」と読む一般的な理解とも合わない。最終的に、分母は 14 でよいと確認できた。
- 位置を、範囲の先頭からの相対番号で書く（`1,3,6/13-26`）。範囲内の値そのものを書けるほうが、元の番号（ページや章の番号など）と照らし合わせやすい。
- 範囲を、別のオプション（`; from=13`）で指定する。値と範囲が離れ、読みにくい。

## 結果

- パーサーだけの変更で済む。描画側は、範囲の開始値を引いて 1 始まりに換算した位置を受け取るので、変更が要らない。
- `3/13-26` のように、`/` の前の個数が範囲の先頭から数えられることに注意が必要。`13/13-26` は「13個が完了」であり、「13が完了」ではない。13 だけが完了を表すには、`,13/13-26` と書く。
- 範囲の開始値や終了値を、ラベルに出す手段はない。必要になれば、ラベルの内容を選べる設定（今後の候補）と合わせて検討する。
